# Foreman 1.1.0-rc.1

Foreman now installs as a complete package with working commands and shared persistent state. This public release candidate is available for testing while final live advisory quality acceptance remains pending.

## Install

Requires Node 22.19 or newer and a supported AI host.

```sh
npx --yes --package=https://github.com/fatihguner/foreman/releases/download/v1.1.0-rc.1/foreman-sh-1.1.0-rc.1.tgz foreman-sh init
```

Add `--platform codex` or `--platform all` as needed. Use `--workspace /path/to/project` to select the destination. Existing files are preserved. For an upgrade, back up your workspace and review old generated files before replacing them; repeated initialization only fills missing files.

Claude Code plugin installation:

```text
/plugin marketplace add fatihguner/foreman
/plugin install foreman@foreman-marketplace
```

Plugin commands use names such as `/foreman:solo` and `/foreman:apply`. Project commands use `/solo` and `/apply`. In Codex, invoke `$foreman` with the desired operation.

The GitHub release includes the npm tarball and its SHA-256 checksum. The npm registry's stable channel remains separate; this candidate is intended for the `next` channel once npm publishing is configured.

## Changes

- Complete Claude and Codex plugin resources: 159 packaged skills including the router, 46 command wrappers, diagnostics, playbooks and supporting content.
- A compiled OpenClaw adapter using the real SDK and registering 10 tools.
- Shared profile, language, solo and Stoic settings, implementation tracking and playbook checkpoints with atomic persistence.
- Strict YAML and typed-reference checks, explicit aliases and safe name resolution.
- Portable maintenance scripts, non-overwriting installation, staged Git validation and a reproducible package build.
- Shared advisory rules that distinguish evidence from hypotheses, respect solo capacity and require confirmed state writes.

## Verification and limitations

The automated suite has 23 tests, with local macOS and Linux runs passing. CI additionally checks Node 22 and 24, release metadata, generated bundle freshness, and installation of the actual npm tarball. Real Claude command discovery, profile writes and cross-session recall were exercised. OpenClaw loaded the plugin and its 10 tools.

Automated checks do not establish advisory answer quality. Preliminary live answers showed unsupported causal claims, invented targets and language drift. Stronger instructions are included, but the complete final live regression has not yet passed. The earlier exploratory runs used a different model and shared workspace, so they are not a controlled comparison. Codex file installation and resources are verified; a live Codex model session is still unverified.

Foreman is free under the MIT license. Your AI host account and any model usage are separate. Runtime data belongs in `.foreman/`, outside version control.
