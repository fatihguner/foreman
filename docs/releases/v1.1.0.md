# Foreman 1.1.0

Draft release notes. Live advisory and host-session acceptance is pending; this version has not been published.

Foreman 1.1.0 brings the complete installer, shared state runtime and repaired plugin bundles to the stable release channel.

## Installation after publication

Requires Node 22.19 or newer and a supported AI host.

```sh
npx foreman-sh@1.1.0 init
```

Add `--platform codex` or `--platform all` as needed. Use `--workspace /path/to/project` to select the destination. Existing files are preserved: repeated initialization fills missing files and does not update existing generated files. Back up and review those files when upgrading.

Claude Code project commands include `/solo`, `/apply` and `/foreman-resume`. Plugin commands use the `/foreman:` namespace. In Codex, invoke `$foreman` with the desired operation.

## Changes

- Complete Claude and Codex resources: 159 packaged skills including the router, 46 command wrappers, diagnostics, playbooks and supporting content.
- A compiled OpenClaw adapter using the real SDK and registering 10 tools.
- Shared profiles, language and working modes, task tracking and confirmed playbook checkpoints with atomic persistence.
- Strict YAML and typed-reference checks, portable maintenance scripts and package installation checks.
- Advisory instructions that distinguish evidence from hypotheses, respect solo capacity and require successful runtime writes before claiming persistence.
- Session-only mode and language choices take precedence for the current conversation without changing saved preferences.

## Acceptance status

The 23 automated tests, content validation, TypeScript checks and compilation pass locally. The release candidate passed the macOS/Linux Node 22/24 CI matrix. The stable release requires its own CI run and final live acceptance before publication.

Pending: eight isolated advisory scenarios; fresh Claude and Codex sessions exercising profile recall, blocked and completed tasks, preserved notes and playbook resume. Model answers remain variable; these scenarios provide bounded acceptance evidence, not a guarantee for every model or business situation.

Foreman is free under the MIT license. AI host accounts and model usage are separate. Runtime records belong in `.foreman/`, outside version control.
