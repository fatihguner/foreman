# Foreman 1.1.0

Foreman 1.1.0 brings the complete installer, shared state runtime and repaired plugin bundles to the stable release channel.

## Installation

Requires Node 22.19 or newer and a supported AI host.

```sh
npx foreman-sh init
```

Use `npx foreman-sh@1.1.0 init` to pin this version. Add `--platform codex` or `--platform all` as needed. Use `--workspace /path/to/project` to select the destination. Existing files are preserved: repeated initialization fills missing files and does not update existing generated files. Back up and review those files when upgrading.

Claude Code project commands include `/solo`, `/apply` and `/foreman-resume`. Plugin commands use the `/foreman:` namespace. In Codex, invoke `$foreman` with the desired operation. The GitHub release includes the npm tarball and its SHA-256 checksum.

## Changes

- Complete Claude and Codex resources: 159 packaged skills including the router, 46 command wrappers, diagnostics, playbooks and supporting content.
- A compiled OpenClaw adapter using the real SDK and registering 10 tools.
- Shared profiles, language and working modes, task tracking and confirmed playbook checkpoints with atomic persistence.
- Strict YAML and typed-reference checks, portable maintenance scripts and package installation checks.
- Advisory instructions that distinguish evidence from hypotheses, respect solo capacity and require successful runtime writes before claiming persistence.
- Session-only mode and language choices take precedence for the current conversation without changing saved preferences.
- Research is scoped to available capacity and preserves current commitments. The interview guide no longer promises patterns or statistical confidence from a fixed number of interviews.
- Codex resource paths are explicit, and the Foreman router keeps record discovery within the selected founder.

## Verification and limits

The 23 automated tests, content validation, TypeScript checks and compilation pass locally. CI checks macOS and Linux with Node 22 and 24, including installation of the actual npm tarball.

Eight isolated advisory scenarios were reviewed against the release rubric. Four fresh Claude sessions and four fresh Codex sessions verified profile recall, blocked and completed tasks, preserved notes, playbook resume and selected-founder access. See the [validation report](v1.1.0-validation.md) for the test scope, corrected failures and limitations.

Model answers remain variable. Diagnostic routes are hypotheses to review; suggested schedules and sample sizes must fit the user's actual constraints. These checks do not certify every answer, model or business situation.

Foreman is free under the MIT license. AI host accounts and model usage are separate. Runtime records belong in `.foreman/`, outside version control.
